# Pertenencias de Elena · v3

Seis sprites RGBA creados con la herramienta integrada image_gen mediante la habilidad imagegen. Cada objeto se generó por separado y se copió al proyecto; las regiones de recorte conservan el fondo transparente y las proporciones originales. Se reutilizan en la carga, tarjetas, vista ampliada y botones. Las sombras, cuerdas, colocación y movimiento se dibujan en Godot.
